What the program covers

Ten one-hour sessions, built around examples students already understand — sequences, datasets, and biological logic.

Days 1–4

Programming Foundations

What a programming language actually is, how Python runs, and the basics: variables, types, and operators.

Days 5–8

Python in Practice

Conditionals, loops, lists, dictionaries, and functions — applied to simple DNA and dataset examples.

Days 9–10

Data & Mini Project

A first look at Pandas, then a small end-to-end project analyzing a real dataset.
